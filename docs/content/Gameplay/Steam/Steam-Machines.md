# Steam Machinery

## Alloy Smelter

The first Steam machine you should craft. It gives a better ratio for Bronze and unlocks other alloys.

!!! note
    The Alloy Smelter uses a lot of Steam, use wisely!

## Forge Hammer

The Forge Hammer gives a better, 3:2 ratio on plates instead of the 2:1 ratio with the Hammer tool.

## Macerator

Similar to the Mortar. Gives double yields on ores by breaking them down into crushed ores.

## Compressor

Used to make Compressed Firebricks needed for the Primitive Blast Furnace.
